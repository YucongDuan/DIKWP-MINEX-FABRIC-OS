Operating principle

Purpose → capability discovery → hard-gate filter → Pareto frontier → energy-first selection → bounded execution → outcome measurement → calibration / retirement / causal handoff

The system does not assume that an app is the task. An app, API, model capability, generated function or remote node is one possible carrier of the requested result.

Function borrowing

A node advertises a manifest; a requester obtains a quote; execution requires a bearer credential and a signed, expiring lease restricted to node, capability and call count.

Metered exchange

The reference market creates quotes and output-bound settlement receipts, but moves no real money. A production payment adapter would require independent legal, financial and security review.

Function internalization

Only an openly licensed or explicitly authorized specification may be reimplemented. Conformance tests define the valid scope. Proprietary weights, hidden endpoints and trade secrets are outside the protocol.
